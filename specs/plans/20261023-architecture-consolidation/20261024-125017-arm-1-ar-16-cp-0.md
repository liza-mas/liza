**Decisions local to this plan** (under D-1…D-6):
- **P-1 Tests live in `internal/ops` only.** The load-and-validate proof needs
  `statevalidate`, which imports `db` (RP8), and the archived proof needs the
  real archival operation in `ops` (RP7, RP11). One new test file,
  `internal/ops/merge_c5_utc_test.go`; no `internal/db` test, so race runs on
  `./internal/ops/` only.
- **P-2 In-memory proof calls the resolved function on explicit state.** A
  value read back from disk cannot distinguish local from UTC on a UTC host:
  a local `time.Now()` there marshals with `Z` and decodes as `time.UTC`
  (`arch-context` RP4). `a6-scope` makes extracted transaction helpers take
  explicit state, so the test invokes the resolved function on an in-memory
  fixture and inspects the appended values before any serialisation. If the
  function cannot be called on explicit state without a production change,
  the `a6-scope` contract is unmet: BLOCKED naming it (D-6). No production
  seam is added.
- **P-3 Persisted proof re-executes the test binary (D-3).** Parent runs
  `os.Executable()` with `-test.run=^<own name>$ -test.v` and an environment
  built from scratch: a test-owned helper flag, `TZ=Etc/GMT-2`, and `HOME`,
  `PATH`, `TMPDIR` copied by name from the parent. It never passes
  `os.Environ()` (the older `integration_mutation_lock_test.go:50` pattern is
  not followed, `guards` G1.4). No `time.Local` reassignment, no `t.Setenv`.
  RP4 proved the mechanism red on pre-C5 code under `-race`.
- **P-4 Load compatibility is a non-regression guard (D-2).** Pre-C5 code
  already loads local-offset values, so a test of that property cannot fail
  on pre-C5 code. "Fail on the pre-C5 code" (`scope` Done when) therefore
  binds the tests of the change (P-2, P-3). The compatibility proofs are made
  non-vacuous instead: each first asserts that the stored scalar really
  carries the `+02:00` offset before loading it. The live-state "later write"
  is also proved inside the P-3 child, where the C5 merge itself is the later
  write, and that test is red on pre-C5 code.
- **P-5 Archived fixture uses the real archival path.** Setting
  `terminal_task_archival` alone archives nothing on a write (RP11);
  `EnableAndArchiveTerminalTasks` does (RP7).

## Task 1: Make the two merge timestamps UTC

**Priority:** Must.
**Direct references:** ["scope", "arch-context", "goal-changes", "goal-frozen", "goal-tests", "goal-success", "goal-proof", "goal-docs", "guards", "parent", "areas", "sequence", "oracle", "moves", "shared-files", "change-template", "a6-scope", "a6-provider", "a6-proof", "a6-plan-rules", "a6-plan-flow", "a6-plan-closure", "schema-time"]

**Files:** the file holding the resolved C5 function (two readings only);
new `internal/ops/merge_c5_utc_test.go`; the manifest above. A golden only
if it asserts one of the two values (none expected, D-4).
**Excluded:** every other timestamp, including `recordMergedDeferrals`'s
reading, failure-recording times, the external-merge reconciliation path
and the agent runtime's clean-terminal completion handoff
(`internal/agent`); `db`, `models`, `statevalidate`, rendering, guard data,
oracle files, ADRs, chain-serialized documents, `Makefile`; any refactor,
helper, seam or clock abstraction.

1. **Resolve.** At coding HEAD find the function in the final MERGED
   transaction that appends the completion handoff event and the `merged`
   history entry. If the two readings are not in one function inside that
   transaction, or the function cannot be invoked on explicit state (P-2),
   mark BLOCKED naming `a6-scope`; do not reshape A6 code. Record function
   and file in the checkpoint and in the manifest's C5-utc-memory assertion.
2. **Red.** Write the three tests below and run
   `go test -race -count=1 -run '^TestC5' -v ./internal/ops/` against the
   unchanged production code: tests A and B must fail on the zone
   assertions; test C passes (P-4). Record the red observation in the
   checkpoint.
3. **Change.** Each reading becomes its own clock reading converted to UTC
   (`time.Now().UTC()` or the refactored equivalent); field, entry content,
   order and transaction position unchanged (D-1). Nothing else in
   production code changes.
4. **Green and proof.** Pre-commit on touched files, then the canonical
   commands serially under `env -i` from the child worktree.

**Tests** (in `merge_c5_utc_test.go`; reuse the existing merge fixtures and
seams such as `setupMergeTestRepo`, `recordIndexRefreshes`,
`readStateForTest`, under their coding-HEAD names; no `time.Sleep`; failure
messages report field names, booleans and fixture timestamps only):
- **A `TestC5MergeTimestampsAreUTCInMemory`.** Invoke the resolved function
  on an in-memory fixture state (building the task and request the way its
  existing white-box tests do) between two UTC clock reads; assert the
  appended completion handoff `Timestamp.Location() == time.UTC` and the
  `merged` entry's `Time.Location() == time.UTC`, each within the two reads.
  Red on pre-C5 code on every host (P-2).
- **B `TestC5MergeTimestampsPersistWithZUnderNonUTCZone`.** Parent per P-3;
  it requires child exit 0 and the child's `--- PASS` line for this test
  name (a child that selected nothing fails). Child: assert the local zone
  offset is non-zero (fail, never skip); seed a second, already-MERGED task
  whose completion handoff `timestamp` and `merged` history `time` carry
  `+02:00` offsets; run a real merge (`MergeWorktree`) on the fixture task;
  parse the raw state YAML and assert (a) the merged task's two scalars end
  in `Z`, (b) the seeded task's two scalars are byte-identical to what was
  seeded, (c) a fresh read returns the seeded instants (`Equal`). Red on
  pre-C5 code (RP4: two `+02:00` values persisted).
- **C `TestC5LocalOffsetMergeTimestampsLoadAndSurviveWrites`.** In-process,
  two subtests on a merged fixture made valid for full validation (it
  carries a submission handoff, RP6), whose two values are rewritten to the
  same `+02:00` instant:
  - *live:* the raw `state.yaml` holds both offset scalars (non-vacuity);
    `Read` returns equal instants; `statevalidate.ValidateStateFile(statePath, true, nil)`
    returns nil; an unrelated later state write (e.g. registering an agent)
    leaves both raw scalars byte-identical.
  - *archived:* `EnableAndArchiveTerminalTasks` archives the task; its
    archive object's `value_yaml` holds both offset scalars (non-vacuity);
    `Read` restores the task (`TerminalArchive != nil`) with equal instants;
    validation returns nil; an unrelated later write leaves the stub's
    archive digest and the object's offset scalars unchanged.

**Done when:** at coding HEAD after every `arm-1-ar-15-cp-0` coding child
merged, the production diff is exactly the two readings converted to UTC in
the resolved function; tests A and B fail on the pre-C5 code and pass after;
test C passes and asserts its offsets before loading; no golden or oracle
file changed (expected delta empty, D-4); the manifest names the resolved
function and file; C0–C4 pass.

Mappings (Cn = validation index n): C5-utc-memory → test A at C0, assertion
naming the resolved function and file; C5-utc-persisted → test B at C0;
C5-load-live, C5-load-archive, C5-later-write → test C subtests at C0
(test B adds the live later-write case); C5-proof → `make test` at C1; C2–C4 run as
shared proof. Approved: C5-sites, C5-minimal-diff, C5-goldens, C5-sequence,
C5-environment, C5-docs.
