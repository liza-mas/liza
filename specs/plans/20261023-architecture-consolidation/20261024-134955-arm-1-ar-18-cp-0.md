**Plan decisions** (local data-flow choices within D-2–D-4; no new semantics):

- **PD-1 Helper shape.** Each of the four helpers (whatever function and file
  Scope 17 placed them in) takes the directory explicitly and calls
  `gitpkg.CombinedOutput(dir, …)` (`check-ref-format --branch <name>`,
  `branch <name> HEAD`) or `gitpkg.Output(dir, …)` with stdout discarded (both
  `rev-parse --verify` checks), argument vectors unchanged (D-2). No wrapper,
  runner or option is added; `gitpkg.Command` stays for `git/patchid_exec.go`
  (out of scope).
- **PD-2 Timeout first.** Before reading a non-nil error as a negative answer,
  each `check-ref-format` and `rev-parse` call tests
  `errors.As(err, &*gitpkg.TimeoutError)` and returns that error unchanged;
  `branch` keeps `git branch failed: %w: %s`, which already wraps it (D-4).
- **PD-3 Validation timeout prefix.** At the MAS init entry, a branch-name
  validation error that wraps `*gitpkg.TimeoutError` is returned as
  `failed to validate branch name %q: %w`, never under `invalid branch name %q:`
  (that prefix would read the timeout as an invalid name, D-4). The integration
  branch call sites keep `failed to create integration branch %q: %w` for every
  error, a timeout included: it states a failure, not an answer. All other text
  is today's.
- **PD-4 One discovery, failure where it is.** MAS init calls the project-root
  discovery it calls today (`paths.LizaPathsFromGit()` at `73bcdd1ed`) once,
  before branch-name validation, keeps its result and error, validates in
  `ProjectRoot()` on success or in `""` (process directory) on failure, and at
  today's position returns `failed to setup paths: %w` with the kept error
  before `warnLegacyProjectRoot` (D-3). The integration-branch check and
  creation receive `ProjectRoot()`.
- **PD-5 Test levels.** P1–P3 drive the exported MAS init entry in-process
  (`InitCommandWithConfig` at `73bcdd1ed`), so each fails on pre-C4 production
  code by behaviour rather than by compilation; P4 is guard data plus build;
  P5 is the live oracles and the moved fixture.
