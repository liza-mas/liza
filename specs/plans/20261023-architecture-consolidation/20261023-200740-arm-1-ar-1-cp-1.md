### Comparison, Provenance and Sensitivity

`harness-plan` D-3/D-4 normalizes timestamps and hex identifiers. Applying it indiscriminately
would erase required fixed values. Under `scope` AC1, supply a small stdlib-only raw-state
comparator in `helpers_test.go`: frame `# before`/`# after`, read/compare exact bytes, fail
with the golden path on missing/mismatch, and honor the harness's `ORACLE_WRITE=1` write-mode
protocol when the entry point runs the package on its disposable baseline. All output stays
under `testdata/golden/state/`. Do not call the harness's blanket state normalizer first.
This local capability does not change the harness or its entry-point protocol.

All stored times and identifiers in these cases are fixture-derived and stay verbatim.
Error outcomes use booleans and stable operation labels rather than OS-specific error text
or temporary absolute paths. Observe refusals with independent filesystem reads; never
replace an error with a synthetic success. Sorted relative filenames exclude only recognized
lock and lock-owner files, not unexpected data files. Snapshot encoding uses explicit labels
and lengths or JSON string encoding so newline-containing data remain unambiguous.

After committing inputs, create missing goldens only with:

`env -i HOME="$HOME" PATH="$PATH" TMPDIR=/tmp go run ./internal/testhelpers/oracle/cmd/regen -mode write-new -pkg ./internal/oracle/a1/persist/...`

The reproduction baseline is the ledger's starting commit `96c9ad69aee983ce2b929dd681b6ba43bf920535`;
this task writes no ledger record. Verify the start production equality at implementation time;
if upstream production moved meanwhile, apply the inherited adapter rule or raise its conflict,
never silently generate from HEAD. Missing goldens in ordinary tests must fail without writes.

Sensitivity is an opt-in integration proof, not part of the ordinary suite's time budget.
`TestOraclePersistenceTamper` skips unless `ORACLE_VERIFY_TAMPER=1`, and also skips in write
mode. It uses one disposable clone of the committed candidate HEAD, syncs embedded assets
there, and verifies an unmodified live run and filtered check first. Enumerate all nine
goldens (assert the set equals this inventory). For each, preserve its original bytes, append
an unmistakable extra line, then run the three surface tests and the filtered regeneration
check in that clone. Require both nonzero results and each output to name the altered path;
restore that file before the next case, including failure cleanup. Use one clone and serial
mutations, with no commit of corrupt data and no changes to the working project. Missing or
extra inventory entries fail the proof rather than being silently skipped.

Clone commands use Git only in disposable space; pin the clone checkout to the captured
candidate SHA, not its default branch. Children use the delivered `oracle.ChildEnv` policy
(`harness-plan` D-14), with Go cache resolution as that policy requires; do not pass the tamper
enable variable to nested tests, and run nested tests with the explicit three-test selector
to prevent recursion. No provider CLI, repository live runtime directory, host environment
dump, installed-binary replacement or network service is involved. Raw module-path literals
are structural test imports permitted by G1.3.
