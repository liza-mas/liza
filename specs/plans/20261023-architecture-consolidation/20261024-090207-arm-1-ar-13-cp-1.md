and Acceptance Contract parity, pre-commit and independent plan review.
Doc Impact: this plan and its output JSON. Test Impact: none for planning;
children own oracle additions, white-box moves and manifests.

pure candidate construction on `*models.State`; Task 2 owns blackboard,
integration authorization, Git reads, cleanup and alerts. One diff over the

regressions. Fresh and recovery generation stay in one task because they must
share the same builders (`scope` Allocation). Tasks 3 and 4 are independent
concerns in separate files with distinct oracle surfaces (G2, G3).

`direct_coding_allocation.go` (119 lines) and `descendant_dependencies.go`
(99 lines) were reviewed for S1, cohesion and K7 (RP5): no key, no finite
vocabulary literal, each one cohesive concern. No edit is allocated; a child
may touch them only for a call-site edit its own move requires.

No architecture decision, package, dependency, configuration field, exported
signature change, shim or generic transition framework is introduced
(`a4-context`, `a4-shims`). Provider Ask Inventory: N/A; no shared interface
is frozen (`a4-probes` RP9). The software-architecture-review affinity informed
the concern partition without broadening scope.

## Common Rules

Local execution directions under the referenced contracts:

- **Reduce in place, then move.** Shrink each listed offender at its original
  name and file until within S1 before moving any of its code; a moved or
  renamed offender over the limit fails the guard (`size`). Retain the names
  and signatures of `proceedInner`, `recoverCrashedTransition`,
  `computeInheritedDeps`, `isTransitionIncomplete`, `buildChildTask`,
  `validateOutputEntry`, `findSCCs` and `proceedTransaction`'s callee contract:
  white-box tests and the Scope 3 file `plan_replacement.go` call them (RP7).
  `plan_replacement.go` is not edited by this plan.
- **New files.** Private concern files in `internal/ops` (suggested names
  below), each within S1. Re-find symbols at coding HEAD; A3 concern splits
  and A1 vocabulary have landed by then. A plan premise contradicted at coding
  HEAD is surfaced, not silently adapted (mark BLOCKED when it changes scope).
- **K1 and ordering.** No Git or `exec` moves into or out of a `Modify`
  callback. Snapshot preflight, completion linearization/authorization, the
  single `Modify`, post-commit `cleanupRetiredOriginals`, alerts and log
  warnings keep their order. `time.Now().UTC()` stays at its current call
  points. No new mutation site (`mutation`).
- **Errors.** Messages, wrapping, `%w` sentinels (`errTransitionAlreadyExecuted`,
  `errManyToOneCohortIncomplete`, `handoffInputError` classes), first refusal
  and check order are unchanged; extraction adds no validation and swallows
  nothing (`a4-components`).
- **K7.** Consume owner vocabulary; never redefine an A1/A3 set in `ops`.
  Values entering history `Extra`, error text or other `any`/string sinks are
  converted to `string` at insertion, preserving bytes. If an owner did not
  deliver a constant for an occurrence, leave the literal unchanged: the A4
  K7 inventory and reconciliation belong to Scope 6 (`arm-1-ar-13-cp-5`).
  Configured identities (role-pair names, transition names) stay dynamic.
- **Oracles first.** Existing goldens, fixtures and driver files are unchanged
  except under the `goal-tests` exceptions. New cases live in new driver files
  with new fixtures, registered through the package's additive seams
  (`helperOps`, `fixtureRecipes`); goldens are created only by
  `go run ./internal/testhelpers/oracle/cmd/regen -mode write-new -pkg ./internal/oracle/a4`
  from the starting tree, committed in an oracle-only commit before the
  production edit they guard. No `time.Sleep` (`a4-oracle`; RP9). A case that
  cannot be made deterministic without editing existing oracle files marks
  the task BLOCKED naming it before any production edit.
- **White-box tests** move with code; what they asserted stays asserted.
  Mechanical updates (file placement of tests) are expected; behavioral
  expectation changes are not authorized.
- **Guard data.** Each task removes only its keys from
  `internal/testguard/archguard/area_a4_test.go` (Task 1 lowers the
  `proceed.go` ceiling to its measured length); Layers, Allowlist and S2 stay
  empty. A key that cannot reach S1 by concern separation is not converted to
  S2 locally: mark BLOCKED (`size`).
- **Proof.** Run pre-commit on every touched file, then the canonical commands
  serially from the child worktree under `env -i HOME="$HOME" PATH="$PATH" TMPDIR=/tmp`.
  Disposable Git fixtures only; no providers, live state, install or push.
  The 600 s shell cap means waiting in the same foreground session.
