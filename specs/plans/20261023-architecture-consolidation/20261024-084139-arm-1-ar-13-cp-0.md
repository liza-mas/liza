   PR URL/number, tested full SHA, Linux/Windows check names and results, UTC
   observation and the maintainer's ruling. Windows CI is the only run of
   A3's windows-tagged code paths (`exec_windows.go`,
   `shell_runner_windows.go`, `delete_agent_process_windows.go`); local C2

   the old/new distinction; documentation-only deltas are identified by diff.
