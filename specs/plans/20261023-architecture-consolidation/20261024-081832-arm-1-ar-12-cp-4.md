## Common Rules

Local execution directions under the referenced contracts.

- **Freeze and wire.** No `Marshal*`/`Unmarshal*`/`IsZero` method on a new type.
  Values entering `any` maps, templates, payload hashing, fingerprints, history
  `Extra`, anomaly `Details` or a later `.(string)` assertion are converted to
  `string` at insertion. Persisted and hashed fields, model fields and
  presentation-wire result fields stay string-kinded. No validation, default,
  alternate branch or configuration field is added.
- **K1 and ordering.** No Git or `exec` moves into or out of a `Modify`
  callback; locks, runtime-input consumption, launch prerequisites, effect and
  warning order are unchanged. Local timestamps stay local; C5 sites are
  untouched.
- **X2/X7.** Untyped constant arguments at non-A3 callers compile unchanged and
  stay as written: replacing A4–A7 literals is their area's adoption (X7). A
  non-A3 edit is limited to the conversion or type substitution Go type identity
  requires, with all implementations and test doubles; no caller logic changes.
- **Oracles.** Existing goldens, fixtures and drivers are unchanged except the
  `goal-tests` exceptions. New cases use new driver files and fixtures, are
  generated only with the delivered `regen -mode write-new` from the starting
  tree, and are committed before the production edit they guard.
- **White-box tests** move with code; what they asserted stays asserted.
  Behavioural expectation changes are not expected; mechanical updates are.
- **Inherited state.** Re-find symbols at coding HEAD; Scopes 2–4 will have
  split A3 files. A plan premise contradicted at coding HEAD is surfaced, not
  silently adapted (BLOCKED for a plan correction when it changes scope).
- **Proof.** Run touched-file pre-commit, then the task's canonical commands
  serially from its worktree under `env -i HOME="$HOME" PATH="$PATH" TMPDIR=/tmp`.
  No providers, no live state, no install or push.
