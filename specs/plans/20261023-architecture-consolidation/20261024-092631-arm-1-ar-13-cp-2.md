  `liveReplanSuccessor`, `dedupeStrings`, `resolveReplanTarget` and every
  `PlanHandoffDomain` method: other files and tests call them (RP7). No X2
  caller edit is expected; if one is needed it changes no caller logic.
- **New files.** Private concern files in `internal/ops` (suggested names per
  task), each within S1. Re-find symbols at coding HEAD: A3 splits, A1
  vocabulary and Scope 2 have landed by then. A premise contradicted at coding
  HEAD is surfaced; mark BLOCKED when it changes scope.
- **K1, atomicity and ordering.** One `Modify`/`ModifyWithAgentAuthority` per
  operation as today; private steps receive the explicit state, resolver,
  Git handle and actor and own no lock. Pre-lock reads, in-lock checks,
  history appends, candidate validation, post-commit log and post-write
  validation keep their order. `time.Now().UTC()` stays at its call points.
  No new mutation site (`mutation`). The listed K1 inherited exceptions stay
  in their transaction (`k1-ruling`); no Git or `exec` is added to a callback.
- **Errors.** Messages, wrapping (`replan failed: %w`, `amend-plan failed: %w`,
  `plan-check failed: %w`), `PreconditionError`/`PostWriteValidationError`
  types, first refusal and check order are unchanged; extraction adds no
  validation and swallows nothing (`a4-components`). The pass refusal's
  `lineageRepairHint` suffix stays.
- **K7.** Consume owner vocabulary; never redefine an A1/A3 set. Values
  entering history `Extra`, anomaly `Details`, alignment history or error text
  are converted to `string` at insertion. Without a delivered owner constant
  the literal stays; Scope 6 owns the A4 inventory. Configured identities
  (role-pair, transition and role names) stay dynamic.
- **Oracles first.** Existing goldens, fixtures and drivers are unchanged
  except under the `goal-tests` exceptions. New cases live in new driver
  files with new fixtures, registered through the additive seams
  (`fixtureRecipes`, `fixtureBaseOmissions`, `helperOps`); goldens are created
  only by
  `go run ./internal/testhelpers/oracle/cmd/regen -mode write-new -pkg ./internal/oracle/a4`
  from the starting tree, committed in an oracle-only commit before the
  production edit they guard. No `time.Sleep` (`a4-oracle`). A case that
  cannot be made deterministic without editing existing oracle files marks
  the task BLOCKED naming it before any production edit.
- **White-box tests** move with code; what they asserted stays asserted.
  Mechanical updates (test file placement, call sites of moved private
  helpers) are expected; behavioral expectation changes are not.
- **Guard data.** Each task removes only its keys from
  `internal/testguard/archguard/area_a4_test.go`; Layers, Allowlist and S2
  stay empty. A key that cannot reach S1 by concern separation is not
  converted to S2 locally: mark BLOCKED (`size`).
- **References.** Update `INVARIANTS.md` or
  `specs/architecture/blackboard-schema.md` only where a cited file or symbol
  moves (rows listed per task, RP8), without changing meaning.
- **Proof.** Run pre-commit on every touched file, then the canonical commands
  serially from the child worktree under `env -i HOME="$HOME" PATH="$PATH" TMPDIR=/tmp`.
  Disposable Git fixtures only; no providers, live state, install or push.
  The 600 s shell cap means waiting in the same foreground session.
