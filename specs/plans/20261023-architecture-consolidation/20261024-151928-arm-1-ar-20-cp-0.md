## Common Rules

Local execution directions for Tasks 2–5 under the referenced contracts:

- **Reduce in place, then move.** Shrink an offender at its name and file below S1 before moving or
  renaming it; remove its ratchet entry in the commit that brings it within threshold. A file key
  goes only when the file is within 800 lines by moving whole concerns into new files of the same
  package (`size`). No S2 exception is planned: a data-like one goes to A9 S2 data with rationale and
  an overview handoff note for Scope 25; any other key that cannot reach S1 by concern separation
  marks BLOCKED with `--human-action` (`size`).
- **Concerns, not slices.** Each offender becomes ordered orchestration over cohesive steps (S3);
  explicit local outcome values may replace nested branches with identical values and control
  effects. No event bus, generic state machine, service, interface with one implementation,
  dependency or configuration field (K5, K6, D4).
- **Oracle first.** Delivered oracle files and goldens are not edited except the ADR-0219 twin rule
  for a call-site-only adapter edit (`adr-0219`). Oracle additions are black-box drivers in
  `internal/oracle/a9/` with fixtures; goldens come only from
  `go run ./internal/testhelpers/oracle/cmd/regen -mode write-new -pkg ./internal/oracle/a9/...`
  from the starting tree, in an oracle-only commit before the production edit they guard (E5).
- **Characterize first.** Each unit lists its preserved behaviours (PB items). Before its first
  production edit the coder maps every PB item to a named existing test, or adds a `TestA9…`
  white-box test, and runs the mapped set green on the unchanged tree; the manifest records the
  map and that run. Tests characterize through functions that exist before and after the edit.
- **White-box tests** move with code; what they asserted stays asserted. The manifest records the
  assertion-preservation map (old test → new location).
- **Re-find at coding HEAD.** A8 and later deliveries (names, files) are adopted as delivered; a
  contradicted premise that changes scope marks BLOCKED naming it.
- **Preserved sites.** C1 lease values and the `terminal-1` literal (`supervisor.go`,
  `strategy_reviewer.go`), C2 tool-name policy and stored provider, C3 stop matching, and every C6
  mutation body and `ModifyWithAgentAuthority` closure stay in `internal/agent` within their
  transaction boundaries; a named helper inside `agent` is allowed, a move into `ops` or a new
  package is not (X8, `mutation`). D33 inherited revalidation stays inside its transaction; the
  count of Git/exec calls inside `Modify` does not grow. Generation fences, liveness overlay and
  sequence, masking, validation refusals and lock order are unchanged. Record moved C-site names.
- **K7 per unit.** Finite control-flow values in touched files become typed or named constants of
  their D6 owner with unchanged bytes; adopt delivered `roles`, `pipeline`, `models` and `alerts`
  constants; YAML role names, tool names, profile names, role-pair identities and configured values
  stay dynamic (`adr-0045`). Leave C1's terminal and lease sites to C1.
- **Branding (G1.3).** Added lines carry no raw default-brand literal outside ADR-0092 categories;
  record the scan of the diff's added lines.
- **Proof.** Pre-commit on touched files (Go, JSON and Markdown hooks match their paths), then the
  canonical commands serially from the child worktree under
  `env -i HOME="$HOME" PATH="$PATH" TMPDIR=/tmp`; disposable fixtures only; no providers, live
  state, install or push; never print inherited environment values. `make test` and race exceed the
  600 s foreground cap: run them as background jobs waited in bounded foreground steps. Cn names the
  command at validation index n of the task's contract.
