## Common Rules

Local execution directions under the referenced contracts:

- **Reduce in place, then move.** Shrink each offender at its original name
  and file to within S1 before moving any of its code (`size`). Keep the
  names and signatures of every exported entry (`RetargetDependency*`,
  `NarrowInheritedDependencies*`, `LoadNarrowSelectionsFile`,
  `ApplyDependencyRepair*`, `RepairSupersededDependencies*`,
  `DeferProviderDependency`, `ReserveProviderWithAuthority`), their input and
  result types, and of the shared helpers other files call (RP6):
  `applyDependencyUpdatesInState` (`replace_task.go`),
  `mergedPlanLineageRepair` (`plan_check.go`), `pruneDownstreamDependencies`,
  `rewriteActiveDependents`, `canonicalize*`, `operationalOutputMayBeConsumed`,
  `rejectUnmetDependencyOnExecutingConsumer`, `validateDependencyDirection`,
  `mergeInheritedDeps`, every `provider_dependencies.go` function,
  `reserveSuccessorsInState`, `addReservation`, `rejectDroppedReservations`.
  No X2 caller edit is expected; if one is needed it changes no caller logic.
- **New files.** Private concern files in `internal/ops` (suggested names per
  task), each within S1. Re-find symbols at coding HEAD: A1 vocabulary, A3
  splits and vocabulary (`a3-vocab` retypes the safe-action/effects
  parameters and converts A4 string variables feeding them) and Scopes 2–3
  have landed by then. A premise contradicted at coding HEAD is surfaced;
  mark BLOCKED when it changes scope.
- **Atomicity and ordering.** One `lifecycleMutation`/`Modify` per operation
  as today. Private steps receive the explicit state, resolver, request
  inputs, actor and `now` and own no lock. Pre-lock request checks, in-lock
  admission (task lookup, observed copy, request, receipt replay) before any
  eligibility check, history appends, `ValidateCandidate`, receipt completion,
  the post-commit activity log and its warning keep their order.
  `time.Now().UTC()` stays at its call points. No intermediate graph is
  published, a skipped child is never mutated, provider output indexes are
  never remapped, and no descendant or reservation wait is dropped (`scope`
  CONTRACT). No new mutation site (`mutation`).
- **Errors.** Messages, wrapping (`failed to retarget dependency: %w`,
  `failed to narrow inherited dependencies: %w`, `failed to apply dependency
  repair: %w`, `failed to repair superseded dependencies: %w`,
  `defer provider dependency: %w`, `reserve-provider: %w`),
  `PreconditionError`/`OperationalError`/`NotFoundError` types, each
  operation's lifecycle outcome and safe action per refusal, first refusal
  and check order are unchanged; extraction adds no validation and swallows
  nothing (`a4-components`).
- **K7.** Consume owner vocabulary; never redefine an A1/A3 set (`a4-context`).
  Adopt delivered A3 safe-action/effects constants (`a3-vocab`) and A1
  cardinality constants (`a1-pipeline-vocab`) in touched functions. Values
  entering history `Extra`, error `Details`, log actions or result fields are
  converted to `string` at insertion; JSON field types stay `string`. Without a
  delivered owner constant the literal stays (the models-owned `replanned`
  marker, the cross-area `operator_cli`/`operator` source literals); Scope 6
  (`arm-1-ar-13-cp-5`) owns the A4 inventory reconciliation. Configured
  identities (role-pair, transition, role names) stay dynamic.
- **Oracles first.** Existing goldens, fixtures and drivers are unchanged
  except under the `goal-tests` exceptions. New cases live in new driver
  files with new fixture state files (name prefix per task: `direct-`,
  `batch-`, `narrow-`, `wait-`), registered only through the additive seams
  (`fixtureRecipes`, `fixtureBaseOmissions`, `helperOps`) under distinct keys;
  replay cases rerun the identical command with one
  `--request-id`/`--expected-transition` pair inside the driver, as
  `runD35Success` sequences commands. Goldens are created only by
  `go run ./internal/testhelpers/oracle/cmd/regen -mode write-new -pkg ./internal/oracle/a4`
  from the starting tree, committed in an oracle-only commit before the
  production edit they guard. No `time.Sleep` (`a4-oracle`). Fixtures are
  valid at the starting commit (`a4-oracle` Fixtures). A case that cannot be
  made valid and deterministic without editing existing oracle files marks
  the task BLOCKED naming it before any production edit.
- **White-box tests** move with code; what they asserted stays asserted.
  Mechanical updates (test placement, call sites of moved private helpers)
  are expected; behavioural expectation changes are not.
- **Guard data.** Each of Tasks 1–3 removes only its keys from
  `internal/testguard/archguard/area_a4_test.go`; Task 4 does not edit it.
  Layers, Allowlist and S2 stay empty. A key that cannot reach S1 by concern
  separation is not converted to S2 locally: mark BLOCKED (`size`).
- **References.** Update `INVARIANTS.md` only where a cited file loses the
  code it is cited for (rows listed per task, RP8), without changing meaning.
- **Proof.** Run pre-commit on every touched file, then the canonical commands
  serially from the child worktree under `env -i HOME="$HOME" PATH="$PATH" TMPDIR=/tmp`.
  Disposable Git fixtures only; no providers, live state, install or push.
  The 600 s shell cap means waiting in the same foreground session.
