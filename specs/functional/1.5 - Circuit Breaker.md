# Circuit Breaker

Systemic failure detection and recovery.

## Description

The circuit breaker is an observer that detects patterns indicating upstream problems — issues that task-level fixes cannot resolve. It reads anomalies logged by agents plus planning task review evidence, identifies systemic patterns, and escalates to human intervention.

The `planning_review_churn` pattern classifies four or more durable planning rejection cycles as `PLANNING_CONVERGENCE_DEGRADED`; `MERGED` tasks remain eligible so eventual success does not erase convergence cost.

The `blocked_replacement_chain` pattern classifies a `BLOCKED` task whose lineage already had two blocked-recovery replacements as `RECOVERY_CONVERGENCE_DEGRADED`. The same rule refuses the next agent replacement until a human resumes the response for that task and blocked episode (ADR-0171).

The circuit breaker never proposes solutions or modifies artifacts. It observes and reports.

## Boundaries

**In scope:**
- Anomaly aggregation and analysis
- Planning task review evidence, including durable rejection history
- Pattern recognition
- Escalation to human
- Report generation

**Out of scope:**
- Solution proposal (prohibited)
- Artifact modification (prohibited)
- Task-level iteration (see 1.3 Task Management)
